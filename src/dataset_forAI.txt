## USER METADATA INPUT FIELDS:
- userName: User's name or identifier (required for folder structure)
- location: Text description of photo location (e.g., "Paris, France")
- eventDate: Date picker for when photo was taken (defaults to today)
- description: Free text description of the moment/photo
- tags: Comma-separated tags for grouping and albums (e.g., "vacation, beach, sunset")

## FOLDER STRUCTURE IN GOOGLE DRIVE:

**Full User Structure (when user provides meaningful data):**
Moments/
├── [Username]/
│   ├── [Location]/ (if provided)
│   │   ├── [YY-MM-DD]/
│   │   │   └── [firstTag]/ (if provided)
│   │   │       └── photo files

**Simple Fallback Structure (no user data):**
Moments/
├── General/
│   └── photo files (flat structure)

Examples: 
- Moments/John Doe/Paris France/26-02-03/vacation/photo.jpg
- Moments/Jane Smith/26-02-03/family/photo.jpg (no location provided)
- Moments/General/photo.jpg (no username or location provided)

## FALLBACK BEHAVIOR:
- If no meaningful userName AND no location: uses simple "Moments/General/" structure
- If userName provided but no location: "Moments/Username/Date/Tags/"
- If both userName and location provided: "Moments/Username/Location/Date/Tags/"
- If eventDate not provided: uses current date
- First meaningful tag (not "user-upload") used for folder organization

## TAG CATEGORIES:

### BASE TAGS:
- "user-upload" - Always present for user-uploaded content

### CONTENT-BASED TAGS (filename analysis):
- "selfie" - Detected from filenames containing 'selfie'
- "group" - Detected from filenames containing 'group'
- "family" - Detected from filenames containing 'family'
- "travel" - Detected from filenames containing 'travel'
- "vacation" - Detected from filenames containing 'vacation'
- "wedding" - Detected from filenames containing 'wedding'
- "birthday" - Detected from filenames containing 'birthday'

### FILE-TYPE TAGS:
- "jpg", "jpeg", "png", "gif", "webp" - Based on file extension

### QUALITY TAGS:
- "high-quality" - Files larger than 5MB (5,000,000 bytes)
- "compressed" - Files smaller than 500KB (500,000 bytes)

### FALLBACK TAGS (when no content tags detected):
- "memory" - Generic memory categorization
- "photo" - Generic photo categorization  
- "moment" - Generic moment categorization
- "{month}-upload" - Current month (e.g., "february-upload", "march-upload")
